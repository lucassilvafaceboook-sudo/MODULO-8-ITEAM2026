# 🎓 Portal Acadêmico - Projeto Integrador (Módulo 8 - ITEAM)

Sistema Full-Stack para gestão acadêmica, desenvolvido como entrega final do Módulo 8. O sistema permite o controle e visualização de alunos, professores, cursos, turmas e relatórios de matrícula.

## 🚀 Links de Produção

O projeto encontra-se 100% em nuvem, distribuído da seguinte forma:
- **Frontend (Aplicação Web):** https://projeto-escola-iteam.netlify.app/
- **Backend (API REST):** Hospedado no Render (`https://modulo-8-iteam2026.onrender.com`)
- **Banco de Dados:** Hospedado remotamente no **Console - Clever Cloud**

## 📦 Documentação do Banco de Dados

Conforme os requisitos da avaliação, os artefatos de modelagem estrutural estão localizados na pasta `/documentação` na raiz deste repositório:
- **Diagrama Entidade-Relacionamento (DER):** Arquivo `DER_escola_db.pdf`
- **Schema SQL:** Arquivo `escola_db.sql` (contém os scripts de criação do banco e das tabelas).

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express
- **Banco de Dados:** MySQL (Clever Cloud)
- **Deploy:** Netlify (Front) e Render (Back)
